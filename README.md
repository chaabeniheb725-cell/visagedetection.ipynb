Facial Emotion Recognition

Description

Deep Learning project for facial emotion recognition using Python and computer vision.

Objective

The objective is to develop a model capable of recognizing emotions from facial images.

Technologies

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy
* Pandas
* Matplotlib
* Jupyter Notebook

Deep Learning

The project includes:

* Image preprocessing
* Dataset preparation
* Model training
* Model evaluation
* Emotion classification

Project

The complete implementation is available in the Jupyter Notebook:

visagedetection.ipynb
